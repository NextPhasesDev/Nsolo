# Nsolo - Traditional Zambian Board Game

A digital adaptation of Nsolo, a traditional Zambian mancala-style board game.

## Features
- Player vs Player mode
- AI Easy & Hard modes
- Animated stone movement
- Dynamic music system
- African-inspired sound design

## How to Play
- Player A controls the bottom 2 rows (pink)
- Player B controls the top 2 rows (blue)
- Click a cell to pick up and distribute its stones
- Capture opponent stones by landing in your territory
- Most captures wins!

## Requirements
- Java 8 or higher

## Running from Source
```bash
javac src/*.java
java -cp src NsoloGame
```
