# Changelog - Nsolo

## [1.1.0] - 2026-02-10
### Added
- New music system with richer harmonies and bass
- Unique music tracks for each game mode (Menu, PvP, AI Easy, AI Hard)
- Dynamic music intensity - switches to intense music when game is close
- Win and lose sound effects
- Better capture sound (victory arpeggio)

### Changed
- Improved stone drop sound (wooden thud)
- Enhanced AI difficulty balance

### Fixed
- updateBoard() method bug causing compilation errors
- Launch4j Java 25 detection issue

## [1.0.0] - 2026-02-01
### Added
- Initial release
- Player vs Player mode
- AI Easy mode
- AI Hard mode
- Basic sound effects
- Animated stone movement
- Score tracking
