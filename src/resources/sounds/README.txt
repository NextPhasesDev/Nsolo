NSOLO audio asset guide
=======================

Place your .wav files in this folder using these names:
- click.wav
- drop.wav
- capture.wav
- pickup.wav
- complete.wav
- invalid.wav
- win.wav
- lose.wav
- menu_music.wav
- pvp_music.wav
- ai_easy_music.wav
- ai_hard_music.wav
- intense_music.wav

Recommended searches on freesound.org or itch.io:
- "wooden click ui button" -> click.wav (menu and button interactions)
- "stone drop wood board" -> drop.wav (stone sowing feedback)
- "collect chime short success" -> capture.wav (capture event reward)
- "soft pickup pebble" -> pickup.wav (stone pickup loop moment)
- "turn complete ui confirmation" -> complete.wav (turn completion cue)
- "ui error soft buzzer" -> invalid.wav (invalid move warning)
- "victory fanfare short game" -> win.wav (end game win)
- "lose stinger short" -> lose.wav (end game lose)
- "african ambient menu loop" -> menu_music.wav (main menu atmosphere)
- "tribal rhythm strategy loop" -> pvp_music.wav (PvP game loop)
- "calm board game loop" -> ai_easy_music.wav (easy AI mode)
- "tense strategy loop" -> ai_hard_music.wav (hard AI mode)
- "final round intense loop" -> intense_music.wav (close endgame intensity)

Audio notes:
- Use 16-bit PCM WAV when possible.
- Keep SFX short (< 1 second) and normalize levels.
- Keep music loop points clean to avoid clicks.
